MINING PAYOUTS

Give the pool
the right address.

ZecWec pays WEC to a Wcash Mainnet Unified Address with an Ironwood receiver. Your wallet holds the keys. The pool records the payout destination. Your miner uses a separate worker login.

Open ZecWec Pool
Current wallet builds are developer previews

The available desktop packages are unsigned and the Android package is debug-signed. They use a plaintext wallet service. Do not rely on them for material funds. Review the build facts and recovery limits before creating an address.

  1. 01

    Review a wallet build

    Choose a desktop or Android candidate above. Verify its source commit and SHA-256 value before opening it.

  2. 02

    Back up the wallet

    Create or restore the wallet, record the recovery phrase offline, and test recovery with disposable funds. Never give the phrase or a private key to the pool.

  3. 03

    Copy the Ironwood address

    Open Receive. On desktop, use Unified; on Android, use Shielded Address. Create or select an address whose type includes Ironwood, then copy the complete Wcash Mainnet address. The demo address on this page and Zcash addresses are invalid WEC payout destinations.

  4. 04

    Add it to ZecWec

    Paste the address into the pool’s WEC payout setting. The pool validates its chain and receiver. Worker credentials belong in the miner; wallet secrets do not.

More about Wcash
What is Wcash?

Wcash, at w.cash, is an independent network forked from the Zcash codebase, with merged mining and no protocol development tax. Wcash and Zcash are separate networks with separate coins. This wallet is designed for WEC.

How is Wcash Wallet related to Zingo?

Wcash Wallet is based on Zingo and adapted for the Wcash network. The Wcash forks are wallet-mobile and wallet-desktop. Upstream attribution remains with the Zingo mobile and Zingo PC projects. The browser experience on this page is an educational sample with no wallet or network connection.

Is every transaction private?

Privacy depends on the transaction and the recipient’s address. A supported shielded transfer can conceal the on-chain sender, recipient, and amount. A transparent recipient exposes their receiving address and amount. Transfers between pools can reveal information too. Check the recipient and privacy state before sending.

What does “no dev tax” mean?

The protocol does not divert a share of block rewards to a development fund. This is a rule about mining rewards, not a promise of free transactions. Network transaction fees still apply.

How do miners receive WEC payouts?

Create a Wcash Mainnet Unified Address with an Ironwood receiver in the wallet, then save that address as the WEC destination at ZecWec Pool. Keep the recovery phrase and private keys out of the pool and miner configuration. See the mining payout steps.

Who controls my wallet?

You do. A self-custody wallet puts the keys in your hands. Keep your recovery phrase offline in a safe place, and never share it. Anyone with that phrase can control the wallet; losing it can mean losing access to your funds.

Which devices can I use?

There is no supported consumer release. Unsupported developer candidates exist for Android, macOS, Windows, and Linux. Android is debug-signed; desktop packages are unsigned. TestFlight is not available, and the unsigned iOS compile archive is not offered as an install download. Developers can use the linked source build instructions.
